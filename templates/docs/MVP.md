## 문서 목적

## 작성 방법

새 앱에서는 이 파일을 MVP_SCOPE.md로 복사한다. 기존 MVP.md 사용 앱은 이름을 유지할 수 있다. 둘을 동시에 원본으로 관리하지 않는다. 상세 완료 조건은 FR/NFR를 참조한다. 예시는 합성 데이터이며 사용자 승인 없이 확정하지 않는다. 초기에 중복된 완료 조건을 쓰지 말고 상세 FR/NFR 원문 ID로 연결한다.

## 작성 예시

포함 FR-001(실천 기록), 적용 NFR-001(글자 확대), 제외 후보 주간 통계. 완료 조건은 FUNCTIONAL_REQUIREMENTS의 FR-001 원문을 참조한다. 서버 동기화는 가치 검증 전까지 제외 제안이며 사용자 승인 전에는 미확정이다.
