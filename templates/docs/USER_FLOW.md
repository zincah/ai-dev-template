## 문서 목적

## 작성 방법

Phase 4에 FLOW ID별로 기존 1~5절을 반복한다. 신규 프로젝트는 FR ID, 기존 앱은 승인된 REQ 대응표를 사용한다. 예시는 합성 데이터이며 사용자 승인 없이 확정하지 않는다. 초기에 중복된 완료 조건을 쓰지 말고 상세 FR/NFR 원문 ID로 연결한다.
