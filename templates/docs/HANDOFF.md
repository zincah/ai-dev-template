## 문서 목적

사용자 승인된 기획 기준과 미결정을 Codex에 전달한다.

## 작성 방법

Phase 5에 작성하고 기존 1~9절을 채운다. 최종 승인 후 파일을 Git에 저장한다. HANDOFF 안에 자신의 최종 커밋 해시를 미리 적는 대신 인계 시 실제 기준 커밋을 메시지와 PLANNING_STATUS에 기록한다. 예시는 합성 데이터이며 사용자 승인 없이 확정하지 않는다. 초기에 중복된 완료 조건을 쓰지 말고 상세 FR/NFR 원문 ID로 연결한다.

- Codex 순서: 문서 → 일관성 → 미결정 → 기술 제약 → 아키텍처 제안 → 사용자 승인 → 상세 설계 → TASK 분할 → 별도 구현 요청: {{내용}}

## 작성 예시

습관 앱 기획 v0.1의 5단계를 사용자가 승인했고 Critical 0건이다. FR-001·NFR-001이 MVP 기준이며 Q-001 서버 도입 여부는 설계 시작 전에 결정해야 한다. Codex에는 먼저 아키텍처 제안까지만 요청하고 승인 전 상세 설계·구현을 시작하지 않는다.
