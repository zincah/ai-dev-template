# MVP_SCOPE 템플릿 사용 안내

## 문서 목적

첫 출시의 포함·제외 범위를 요구사항 ID로 고정한다. 기존 문서와의 중복을 막기 위해 작성 원본은 [기존 MVP 템플릿](../docs/MVP.md) 한 곳에서 확장·관리한다.

## 작성 방법

이 안내 파일 대신 연결된 원본 전체를 실제 앱 docs/MVP_SCOPE.md로 복사한다. 새 앱에서는 이 파일을 MVP_SCOPE.md로 복사한다. 기존 MVP.md 사용 앱은 이름을 유지할 수 있다. 둘을 동시에 원본으로 관리하지 않는다. 상세 완료 조건은 FR/NFR를 참조한다.

## 필수 작성 항목

원본의 기존 번호별 항목과 “필수 작성 항목”을 채운다. 문서 원본 경로 / 목표 지표 / 검증 기간: {{내용}}

## 작성 예시

포함 FR-001(실천 기록), 적용 NFR-001(글자 확대), 제외 후보 주간 통계. 완료 조건은 FUNCTIONAL_REQUIREMENTS의 FR-001 원문을 참조한다. 서버 동기화는 가치 검증 전까지 제외 제안이며 사용자 승인 전에는 미확정이다.

## 검증 체크리스트

- [ ] 안내 파일이 아닌 연결된 원본을 복사했는가?
- [ ] 원본의 필수 항목과 검증 체크리스트를 완료했는가?
- [ ] 실제 앱에서 같은 목적의 문서를 두 개의 원본으로 관리하지 않는가?
