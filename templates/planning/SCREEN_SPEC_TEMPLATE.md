# SCREEN_SPEC 템플릿 사용 안내

## 문서 목적

화면의 역할·이벤트·상태를 구현 가능한 수준으로 정의한다. 기존 문서와의 중복을 막기 위해 작성 원본은 [기존 SCREEN_SPEC 템플릿](../docs/SCREEN_SPEC.md) 한 곳에서 확장·관리한다.

## 작성 방법

이 안내 파일 대신 연결된 원본 전체를 실제 앱 docs/SCREEN_SPEC.md로 복사한다. Phase 4에 SCR ID별로 기존 1~7절을 반복한다. 완료 조건의 업무 규칙은 FR 원문을 참조하고 화면 검증 조건만 추가한다.

## 필수 작성 항목

원본의 기존 번호별 항목과 “필수 작성 항목”을 채운다. 화면 목록: SCR ID / 이름 / 역할 / 관련 FR·FLOW: {{내용}}

## 작성 예시

SCR-001 오늘 실천 입력 / FR-001 / FLOW-001. 저장 중 버튼 비활성, 성공 시 완료 표시, 저장 실패 시 입력을 유지하고 재시도 안내, 기록 없음은 안내 문구. 서버 단독은 자체 화면 없음의 근거를 적고 USER_FLOW의 소비자 시나리오를 참조한다.

## 검증 체크리스트

- [ ] 안내 파일이 아닌 연결된 원본을 복사했는가?
- [ ] 원본의 필수 항목과 검증 체크리스트를 완료했는가?
- [ ] 실제 앱에서 같은 목적의 문서를 두 개의 원본으로 관리하지 않는가?
