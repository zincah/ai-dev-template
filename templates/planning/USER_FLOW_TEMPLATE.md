# USER_FLOW 템플릿 사용 안내

## 문서 목적

사용자의 정상·예외 흐름을 요구사항과 화면에 연결한다. 기존 문서와의 중복을 막기 위해 작성 원본은 [기존 USER_FLOW 템플릿](../docs/USER_FLOW.md) 한 곳에서 확장·관리한다.

## 작성 방법

이 안내 파일 대신 연결된 원본 전체를 실제 앱 docs/USER_FLOW.md로 복사한다. Phase 4에 FLOW ID별로 기존 1~5절을 반복한다. 신규 프로젝트는 FR ID, 기존 앱은 승인된 REQ 대응표를 사용한다.

## 필수 작성 항목

원본의 기존 번호별 항목과 “필수 작성 항목”을 채운다. FLOW ID / 대상 사용자·역할 / 관련 FR: {{내용}}

## 작성 예시

FLOW-001: 개인 사용자가 SCR-001에서 오늘 실천을 선택 → FR-001 저장 → 결과 표시. 실패하면 입력 보존 후 재시도. 서버 단독은 소비자가 기록 API를 호출해 성공·권한 오류를 처리하는 흐름으로 설명한다.

## 검증 체크리스트

- [ ] 안내 파일이 아닌 연결된 원본을 복사했는가?
- [ ] 원본의 필수 항목과 검증 체크리스트를 완료했는가?
- [ ] 실제 앱에서 같은 목적의 문서를 두 개의 원본으로 관리하지 않는가?
