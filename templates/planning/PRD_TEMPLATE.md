# PRD 템플릿 사용 안내

## 문서 목적

제품 방향과 서비스 범위를 정의하고 상세 요구사항은 FR/NFR 문서를 참조한다. 기존 문서와의 중복을 막기 위해 작성 원본은 [기존 PRD 템플릿](../docs/PRD.md) 한 곳에서 확장·관리한다.

## 작성 방법

이 안내 파일 대신 연결된 원본 전체를 실제 앱 docs/PRD.md로 복사한다. Phase 2에 작성한다. 기존 1~8절을 유지한다. 기존 REQ ID는 제품 수준 식별자로 유지하고 상세 완료 조건은 FR 원문을 참조한다.

## 필수 작성 항목

원본의 기존 번호별 항목과 “필수 작성 항목”을 채운다. 핵심 기능 / 부가 기능 / 기능 간 관계: {{제품 REQ → FR 목록}}

## 작성 예시

REQ-001 습관 실천을 기록한다 → FR-001. 사용자는 개인 사용자이며 Flutter iOS/Android를 우선한다. 동기화 서버 도입은 미확정 Q-001로 관리한다. 상세 입력·예외·완료 조건은 FR-001을 참조한다.

## 검증 체크리스트

- [ ] 안내 파일이 아닌 연결된 원본을 복사했는가?
- [ ] 원본의 필수 항목과 검증 체크리스트를 완료했는가?
- [ ] 실제 앱에서 같은 목적의 문서를 두 개의 원본으로 관리하지 않는가?
